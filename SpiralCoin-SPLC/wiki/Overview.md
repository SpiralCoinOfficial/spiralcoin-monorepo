# Overview

## What SpiralCoin is

SpiralCoin (SPLC) is a crypto trading and on-chain infrastructure platform
being built by SpiralCoin Official. The public product is `www.spiralcoin.net`
— a single-domain web application that combines:

- A **trading platform UI** for crypto markets (currently demo only)
- An **on-chain liquidity layer** (SPLC/USDC seed pool on Arbitrum One — pending deploy)
- A **sponsor recognition system** tied to GitHub Sponsors
- A **wallet identity layer** (MetaMask + SIWE) linked to Auth0 SSO

## What it isn't (yet)

- ❌ Not a live exchange — order routing is mocked
- ❌ Not a token sale — SPLC is not deployed to mainnet
- ❌ Not a security offering — sponsorships are donations, not investments
- ❌ Not regulated yet — not a registered broker-dealer, MTL, or VASP

## Audience

| User | What they get |
|---|---|
| **Visitor** | Read whitepaper, view demo trading UI, browse roadmap |
| **Account holder** | Auth0 login, dashboard, portfolio, watchlist, settings |
| **Wallet user** | MetaMask SIWE binding for on-chain identity proof |
| **Sponsor** | Recognition wall, on-chain attribution, weekly TVL reports (post-launch) |
| **Developer** | Full source on GitHub, SFTP-free auto-deploy via Actions |

## Core principles

1. **Transparency** — every contract address, deployment, and webhook event is logged in the public repo
2. **Bootstrapped funding** — no VC round; founding sponsors via GitHub Sponsors
3. **Custody-light** — wallet binding proves identity but does not custody funds
4. **Compliance-first copy** — no return promises, no "guaranteed" language, soft disclaimers everywhere
