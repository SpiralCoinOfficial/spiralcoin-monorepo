## Title

SpiralCoin — Across-native bridging UX for cross-chain SPLC liquidity

## Summary

SPLC is a LayerZero V2 OFT (Omnichain Fungible Token) live on Arbitrum One,
configured for Base / Polygon / Ethereum. While LayerZero handles the
burn-and-mint at the contract layer, **end-user UX for moving SPLC across
chains is currently rough**. We're requesting $20K to seed the Arbitrum SPLC/USDC
pool AND to integrate Across as the recommended user-facing bridge UI on
spiralcoin.net for moving USDC into the SPLC ecosystem.

## Why this benefits Across

1. **Every new SPLC user buying on Arbitrum needs USDC there first.** Across
   becomes the recommended bridge in our Trading Platform UI.
2. **Cross-chain SPLC pools** (when we deploy on Base / Polygon) will need users
   to bridge between them. We commit to embedding the Across widget over
   alternatives (Stargate, Hop, native bridges).
3. **Volume attribution** — bridge flows from spiralcoin.net carry an Across
   referral tag, so Across gets clean attribution data on a fair-launch token
   ecosystem.
