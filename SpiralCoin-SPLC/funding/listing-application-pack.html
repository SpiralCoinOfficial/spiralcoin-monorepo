1 · GeckoTerminal AUTO-INDEX

No application form required. GeckoTerminal automatically indexes Uniswap V3 pools on Arbitrum within ~24 hours of the first trade. As soon as the SPLC/USDC pool has at least one swap, it will appear at:

https://www.geckoterminal.com/arbitrum/pools/[POOL_ADDRESS_LOWERCASE]

To accelerate indexing

  1. Seed the pool via deployLpAndLock.js (creates pool + adds initial liquidity).
  2. Execute one small swap (e.g. 1 USDC → SPLC) to trigger trade-history indexing.
  3. Wait 1–24 hours for the GeckoTerminal indexer to pick it up.

Trust badge (optional, post-listing)

Once the pool is indexed, request the GeckoTerminal "Verified" badge by emailing info@geckoterminal.com with the values from §0, plus a screenshot of the indexed pool page.

Description (500-word max — paste verbatim)

SpiralCoin (SPLC) is a fixed-supply, transfer-taxed ERC-20 deployed as a UUPS proxy on Arbitrum One. Every transfer between non-exempt addresses skims 3.14% — split 50/50 between an operational treasury and a staking-rewards vault — to fund continued protocol development without inflation, sponsored issuance, or rent-seeking governance proposals. The token inherits OpenZeppelin's audited ERC-20, ERC-20Permit (gasless approvals via EIP-2612), and ERC-20Votes (token-weighted delegation and checkpointing for the upcoming SpiralDAO). Cross-chain mobility is provided by LayerZero V2's OFT standard via burn-and-mint, preserving net global supply across all destination chains. The initial liquidity venue is a SPLC/USDC pair on Uniswap V3 (Arbitrum One, 1% fee tier, full-range), seeded via the open-source deployLpAndLock.js script. The LP position NFT is transferred to a custody contract (SPLCLPLock) that prevents withdrawal of the underlying liquidity for a minimum of 12 months, while still allowing accrued trading fees to be collected by the treasury. The lock contract address, LP NFT tokenId, and unlock timestamp are recorded on-chain and verifiable on Arbiscan. SpiralCoin makes no claim of guaranteed yield, price appreciation, or utility beyond what its on-chain code enforces. Source code, deploy scripts, and deployment records are public at github.com/SpiralCoinOfficial. The full technical whitepaper is available at spiralcoin.net/whitepaper.html.
