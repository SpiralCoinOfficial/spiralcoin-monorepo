# KYC / Dox Checklist — Building Public Trust

> Trading involves risk. Past performance does not guarantee future results.

Doxxing yourself (publicly disclosing your identity) is the single highest-leverage
trust-building action a token founder can take. Anonymous founders get capped at small
launchpads. Doxxed founders get DAO Maker, Polkastarter, CMC verified badge, and CEX
listings.

You said yes to public KYC. Here's exactly what to publish and where.

---

## Personal information to publish

| Item | Where | Required by |
| --- | --- | --- |
| Legal name | LinkedIn, website "About" page | Launchpads, VCs |
| Professional photo | LinkedIn, Twitter, website | All |
| Country / state of residence | Website "About" | KYC providers |
| LinkedIn profile (verified) | Linked from site footer | VCs, launchpads |
| Twitter/X handle (verified blue check helpful) | Linked from site footer | Community |
| Prior work experience | LinkedIn, resume PDF on site | VCs, launchpads |
| Education | LinkedIn | Optional |
| Prior crypto projects (if any) | Website "Team" | Builds credibility |

## Information you do NOT publish

- Home address
- Personal phone number (use a Google Voice or business line)
- Family member identities
- Bank account / financial details
- Wallet seed phrases (obviously)
- Personal SSN / tax ID

## Steps to dox yourself credibly

1. **Update LinkedIn** — current role: "Founder, SpiralCoin". Add description of project.
2. **Create or update website "Team" page** at <www.spiralcoin.net/team> with photo + bio
3. **Twitter/X** — set bio to include "Founder of SpiralCoin (SPLC)". Pin a tweet introducing
   yourself and the project. Apply for blue check if eligible.
4. **Get AssureDeFi badge** — submit ID + selfie + project info, receive badge
5. **Publish KYC certificate** on website footer with hyperlink to AssureDeFi verification
6. **Record a 60-second intro video** — your face, your name, what SPLC is. Post to Twitter
   and YouTube. Embed on site "About" page.
7. **Apply for CoinGecko "Founder verified" badge** post-listing — they cross-check LinkedIn

## What launchpads will ask for (have ready)

- Government-issued photo ID (passport or driver's license)
- Live selfie holding ID
- Proof of address (utility bill or bank statement, less than 90 days old)
- LinkedIn profile URL
- Personal Twitter/X handle
- Project Twitter/X handle
- Project website URL
- Project Telegram URL
- Project GitHub URL
- Audit report URL
- Whitepaper URL
- Pitch deck URL

## Honest considerations

- **Doxing means doxing.** Once your face and name are on AssureDeFi + LinkedIn + Twitter
  attached to a public token, that's permanent. Trolls and scammers will find you. Make
  sure your home address, kids, and financial details are NOT discoverable.
- **Tax visibility.** Public token founders face IRS scrutiny. Have your CPA on speed dial.
- **Security.** Use hardware wallets (Ledger). Use a separate dedicated computer for
  signing transactions. Use 2FA on every account. Use a password manager.
- **Threat model.** People will try to phish you. They'll DM you "I'm from a CEX, here's
  our listing form." They will be lying. Never share private keys or seed phrases.
