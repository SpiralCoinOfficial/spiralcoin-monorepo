# SPLC Deploy Secrets — Setup Guide

These secrets cannot be auto-generated by an AI. Each one ties to a real-world account, billing identity, or signing authority that **only you can create**. Follow this in order; it takes ~15 minutes.

> **Security rule:** Never paste a private key, mnemonic, or API key into a chat window (including this one). Type them directly into `.env` in your editor.

---

## 1. `ALCHEMY_API_KEY` (free, 2 minutes)

1. Go to <https://dashboard.alchemy.com> → sign up / log in.
2. Click **+ Create new app**.
3. Network: pick **Ethereum** (the key works for all chains we deploy to).
4. Copy the **API Key** (not the HTTPS URL — just the key string at the end).
5. Paste into `.env` as `ALCHEMY_API_KEY=...`.

---

## 2. `DEPLOYER_PRIVATE_KEY` (BURN-AFTER-USE key, 3 minutes)

**Do not reuse your personal wallet.** This key only needs gas money and is rendered powerless 60 seconds after deploy (ownership goes to the Timelock).

Option A — MetaMask (easy):

1. MetaMask → click account dropdown → **Add account or hardware wallet** → **Add a new account**. Name it `SPLC-deployer`.
2. Click the three dots → **Account details** → **Show private key** → enter your MetaMask password → copy.
3. Paste into `.env` as `DEPLOYER_PRIVATE_KEY=0x...`.
4. Fund it with ~$15–25 of ETH on each L2 you'll deploy to (bridge from L1, or use [bungee.exchange](https://bungee.exchange)).

Option B — fresh key, offline:

```powershell
# Generates 32 random bytes. NEVER run on a compromised machine.
$bytes = New-Object byte[] 32
[System.Security.Cryptography.RNGCryptoServiceProvider]::Create().GetBytes($bytes)
"0x" + ($bytes | ForEach-Object { $_.ToString("x2") }) -join ""
```

Then derive its address with `npx hardhat console` → `new ethers.Wallet("0x...").address`.

## 3. `TREASURY_WALLET`, `SUPPLY_VAULT_WALLET`, `FOUNDER_WALLET` (Gnosis Safe, 5–10 minutes)

These three addresses hold the 900M premine, 100M founder allocation, and receive 50% of every tax. They **must be multisigs**, not EOAs.

For each one:

1. Go to <https://app.safe.global>.
2. Connect your personal wallet (any L2; pick **Arbitrum** first — you can deploy the same Safe address to other chains later via Safe's "Add network" feature, since CREATE2 gives the same address).
3. Click **Create new Safe**.
4. Name it (`SPLC Treasury`, `SPLC Supply Vault`, `SPLC Founder`).
5. Owners: add **3–5 signer addresses** (your hardware wallet + co-founders + a backup). For founder wallet, 2-of-3 is OK; for treasury, 3-of-5 minimum.
6. Threshold: 3 (treasury), 2 (founder), 2 (supply vault).
7. Pay the Safe deployment gas (~$2 on Arbitrum).
8. Copy the Safe address (starts with `0x`) into `.env`.

**Important:** deploy the Safe on **the chain you'll deploy SPLC to first** (e.g. Arbitrum). For multi-chain deployment, replay the Safe to each chain via Safe UI (same address everywhere).

## 4. Explorer verification API keys (free, 1 key covers everything)

> **Etherscan v2 unified API:** as of 2025, a single Etherscan API key works across
> Etherscan, Arbiscan, Basescan, Polygonscan, and Optimistic Etherscan via the v2 endpoint.
> You only need to create ONE key.

1. Go to <https://etherscan.io/myapikey>
2. Register / log in → **Add** → name it `SPLC` → copy.
3. Paste the same value into **all five** explorer slots in `.env`:

```
ETHERSCAN_API_KEY=<your-key>
ARBISCAN_API_KEY=<your-key>
BASESCAN_API_KEY=<your-key>
POLYGONSCAN_API_KEY=<your-key>
OPTIMISTIC_ETHERSCAN_API_KEY=<your-key>
```

> ⚠️ **Never paste an API key into a chat window, markdown file, or commit message.**
> If you do, immediately delete the key at <https://etherscan.io/myapikey> and create a new one.

## 5. Validate before deploying

```powershell
cd contracts
copy .env.example .env       # then edit .env in your editor
node scripts/validate-env.js
```

If you see `FAILED:` lines, fix them. If you see all `[OK]`, you're ready.

## 6. Deploy (testnet first — always)

```powershell
# 1. Testnet dry run (fund deployer with ~0.05 Sepolia ETH on Arbitrum Sepolia)
npm run deploy:arbitrum-sepolia

# 2. Inspect contracts/deployments/arbitrumSepolia.json
# 3. Test it for 1–2 weeks. Set up Uniswap V3 pool. Run setAmmPair() via DAO.

# 4. Mainnet (only after testnet is stable):
npm run deploy:arbitrum
npm run deploy:base
npm run deploy:polygon
npm run deploy:optimism
```

## 7. Post-deploy hardening (mandatory)

The deploy script already does these for you, but verify on the explorer:

- [ ] `SpiralCoin.owner()` returns the **TimelockController** address, not your deployer.
- [ ] `TimelockController.hasRole(DEFAULT_ADMIN_ROLE, deployer)` returns **false**.
- [ ] `TimelockController.hasRole(PROPOSER_ROLE, SpiralDAO)` returns **true**.
- [ ] Discard or air-gap the `DEPLOYER_PRIVATE_KEY` — it has no power anymore.

---

## What if my .env leaks?

1. **Private key:** immediately send all funds out (Safe is unaffected — Safes don't have private keys).
2. **Alchemy key:** dashboard → **Reset key**.
3. **Explorer keys:** explorer site → **API Keys** → **Delete** → create new.

Once the deployer key is exhausted post-deploy (no longer owns anything), leaks of *that specific key* are harmless. But until you confirm ownership transferred, treat it as live.
